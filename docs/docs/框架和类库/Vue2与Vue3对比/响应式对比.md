# 响应式：Vue 2 与 Vue 3 对比

> 各版本**单独深挖**见：[Vue 2 响应式原理](../Vue2/Vue2/响应式原理.md) ｜ [Vue 3 响应式系统概述](../Vue3/响应式系统概述.md)

## 一览表

| 维度 | Vue 2 | Vue 3 |
| --- | --- | --- |
| 核心手段 | `Object.defineProperty` 劫持**已有属性** | `Proxy` 代理**整个对象** |
| 数组/下标 | 需改写数组变异方法；直接 `arr[i] = x`、改 `length` 易不更新 | 代理可拦截更多操作，新增/删除属性、数组下标等更易覆盖 |
| 新增/删除属性 | 需 `Vue.set` / `Vue.delete` 才能响应式 | 一般可直接增删（在代理对象上操作） |
| 典型代价 | 初始化要递归遍历对象属性 | 运行时代理，与 `Reflect` 配合 |

## Vue 2（简要）

- **对象**：对已有属性做 `get` / `set` 劫持。
- **数组**：通过重写 `push` 等方法及部分路径处理更新。

```js
Object.defineProperty(data, 'count', {
  get() {},
  set() {}
})
```

**常见局限（面试常问）**

- 直接给对象**新增或删除**属性，视图可能不更新。
- 直接通过**下标改数组元素**或改 **`length`**，视图可能不更新。

## Vue 3（简要）

- 使用 **`Proxy`** 拦截对对象的多种操作（读、写、增删属性等）。
- 使用 **`Reflect`** 完成与默认行为一致的操作，便于组合多种拦截逻辑。

```js
new Proxy(data, {
  get(target, prop) {
    return Reflect.get(target, prop)
  },
  set(target, prop, value) {
    return Reflect.set(target, prop, value)
  },
  deleteProperty(target, prop) {
    return Reflect.deleteProperty(target, prop)
  }
})
```
