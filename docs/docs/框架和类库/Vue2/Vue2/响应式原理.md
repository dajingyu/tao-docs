# Vue 2 响应式原理

> 与 Vue 3 的对照见：[Vue2与Vue3对比/响应式对比.md](../../Vue2与Vue3对比/响应式对比.md)

## 1. 数据代理

**总结**：把 `data` / `props` / `methods` 等挂到 `vm` 上，通过 `this.xxx` 访问更方便。

**要点**：遍历 `data` 的属性，用 **`Object.defineProperty`** 在 `vm` 上定义同名访问器，`get` / `set` 实际读写的是原始 `data`。

## 2. 数据劫持（响应式）

**总结**：把 `data` 里每个属性变成「带依赖收集与派发更新」的响应式属性。

**要点**：

- 每个属性对应一个 **`dep`**（依赖管理器）。
- **`get`**：返回属性值，并执行 **`dep.depend()`**，建立 **dep ↔ watcher** 的关联。
- **`set`**：同步更新值，并执行 **`dep.notify()`**，通知相关 **`watcher`** 把**更新视图**的逻辑放入异步队列（数据同步变，DOM 更新异步）。

## 3. 首次渲染

**总结**：解析模板 → 生成虚拟 DOM → 渲染真实 DOM；过程中**读数据会触发 `get`**，从而**建立**上述响应式关联。

**要点**：初始化时创建 **`Watcher`**，渲染中读取表达式 → 触发代理 `get` → 触发劫持 `get` → **`dep.depend()`** 完成依赖收集。

## 4. 更新时

修改 `data` → 触发代理 `set` → 触发劫持 `set` → **`dep.notify()`** → 遍历 watcher → 调度视图更新（常配合 **`nextTick`** 理解更新时机）。
