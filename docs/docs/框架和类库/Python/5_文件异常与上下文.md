# 5. 文件、异常与上下文

## 5.1 读写文件（推荐 `pathlib` + `with`）

```python
from pathlib import Path

p = Path("data.txt")
p.write_text("hello\n", encoding="utf-8")
text = p.read_text(encoding="utf-8")

# 传统 open
with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.rstrip())
```

| 模式 | 含义 |
| --- | --- |
| `"r"` | 读（默认） |
| `"w"` | 写，覆盖 |
| `"a"` | 追加 |
| `"rb"` / `"wb"` | 二进制 |

- **务必指定 `encoding="utf-8"`**，避免 Windows 下乱码。

## 5.2 `with` 上下文管理器

- 进入块时分配资源，离开块时**自动释放**（关文件、释放锁等）。
- 类似 JS 的 `try/finally` 写关文件，但更简洁。

```python
with open("a.txt") as f:
    content = f.read()
# 此处文件已关闭
```

## 5.3 异常处理

```python
try:
    n = int(input("数字: "))
    result = 10 / n
except ValueError:
    print("不是合法整数")
except ZeroDivisionError:
    print("不能除以 0")
except Exception as e:
    print("其它错误", e)
else:
    print("无异常时执行", result)
finally:
    print("总会执行")
```

- **`else`**：try 内无异常时执行。
- **`finally`**：无论是否异常都执行。
- **不要裸 `except:`**，至少 `except Exception`。

## 5.5 主动抛出

```python
if age < 0:
    raise ValueError("age 不能为负")

raise RuntimeError("业务失败") from err   # 链式异常
```

## 5.7 日志（比 print 更适合项目）

```python
import logging

logging.basicConfig(level=logging.INFO, format="%(levelname)s %(message)s")
logging.info("started")
logging.error("failed", exc_info=True)
```

## 5.8 常见坑

| 问题 | 处理 |
| --- | --- |
| 文件未关导致占用 | 用 `with` |
| 读大文件内存爆 | 按行 `for line in f` |
| 路径写死 `\` | 用 `pathlib.Path` |
| 吞掉异常 | 不要空 `except`；至少打日志 |
