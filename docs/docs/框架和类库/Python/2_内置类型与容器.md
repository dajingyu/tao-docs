# 2. 内置类型与容器

## 2.1 不可变 vs 可变

| 不可变 | 可变 |
| --- | --- |
| `int`, `float`, `bool`, `str`, `tuple`, `frozenset` | `list`, `dict`, `set`, `bytearray` |

- **不可变**：「改」会生成新对象；可作 `dict` 的 key（若可哈希）。
- **可变**：原地修改，同一对象 id 不变。

## 2.2 字符串 `str`

```python
s = "hello"
s.upper()           # "HELLO"，原串不变
s[1:4]              # "ell"  切片：[start:stop:step]
len(s)
"a" + "b"
",".join(["a", "b"])  # "a,b"
"  hi  ".strip()

# 常用
"abc".startswith("a")
"1,2,3".split(",")
f"{name=}"          # name='Tom'  调试写法 3.8+
```

## 2.3 列表 `list`

```python
nums = [1, 2, 3]
nums.append(4)
nums.extend([5, 6])
nums.pop()          # 删最后一个
nums.insert(0, 0)
nums[1:3] = [20, 30]

# 遍历删除：倒序或新建列表，避免边遍历边删
```

| 方法 | 作用 |
| --- | --- |
| `append(x)` | 末尾加一个元素 |
| `extend(iterable)` | 末尾合并多个 |
| `pop(i=-1)` | 删除并返回 |
| `sort()` / `sorted()` | 原地排序 / 返回新列表 |
| `index(x)` | 找下标 |

## 2.4 元组 `tuple`

```python
t = (1, 2, 3)
t = 1, 2, 3         # 括号可省略
a, b, c = t         # 解包
x, *rest = [1, 2, 3, 4]  # x=1, rest=[2,3,4]
```

- 固定长度、不可变；函数多返回值常用元组。

## 2.5 字典 `dict`

```python
user = {"name": "Tom", "age": 25}
user["name"]
user.get("email", "")     # 无 key 不报错
user["city"] = "SH"

for k, v in user.items():
    print(k, v)

# 合并（3.9+）
{**a, **b}
a | b
```

| 方法 | 作用 |
| --- | --- |
| `keys()` / `values()` / `items()` | 视图，可遍历 |
| `get(k, default)` | 安全取值 |
| `pop(k)` | 删除并返回值 |
| `setdefault(k, v)` | 无则写入 |

## 2.6 集合 `set`

```python
s = {1, 2, 3}
s.add(4)
s.remove(2)         # 无则 KeyError
s.discard(99)       # 无则忽略

a | b    # 并
a & b    # 交
a - b    # 差
```

- **去重**：`list(set(lst))`（不保证顺序；要保序用 `dict.fromkeys`）。

## 2.7 切片与复制

```python
lst = [0, 1, 2, 3, 4]
lst[::-1]           # 反转

import copy
b = copy.copy(a)        # 浅拷贝
c = copy.deepcopy(a)    # 深拷贝（嵌套可变对象时用）
```

```python
int("42")

str(123)

dict([("a", 1), ("b", 2)])
```

## 2.9 和 JS 对照（查表）

| 操作 | JS | Python |
| --- | --- | --- |
| 长度 | `.length` | `len(x)` |
| 追加 | `.push()` | `.append()` |
| 包含 | `.includes()` | `in` |
| 对象键 | `Object.keys()` | `.keys()` |
| 展开 | `[...arr]` | `[*a, *b]`（3.5+） |
