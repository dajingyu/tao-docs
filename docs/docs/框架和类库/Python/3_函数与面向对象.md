# 3. 函数与面向对象

## 3.1 函数定义

```python
def greet(name: str, prefix: str = "Hi") -> str:
    """返回问候语"""
    return f"{prefix}, {name}"

greet("Tom")
greet("Tom", prefix="Hello")
```

- **类型注解**可选，运行时不强制；配合 `mypy` 等做静态检查。
- 参数顺序：**位置参数 → 默认参数 → `*args` → 关键字-only → `**kwargs`**。

```python
def demo(a, b=0, *args, flag=True, **kwargs):
    pass

demo(1, 2, 3, flag=False, extra=99)
```

## 3.2 参数传递

- Python 是 **「对象引用传递」**：不可变对象像传值，可变对象像传引用。
- **默认参数不要用可变对象**：

```python
# ❌
def bad(x, items=[]):
    items.append(x)
    return items

# ✅
def good(x, items=None):
    if items is None:
        items = []
    items.append(x)
    return items
```

## 3.3 作用域

```python
x = 1

def f():
    global x      # 修改模块级 x
    x = 2

def g():
    y = 1
    def h():
        nonlocal y
        y = 2
```

- 读变量：先局部 → 外层 → 全局 → 内置（LEGB）。

## 3.4 匿名函数与内置高阶

```python
sorted(items, key=lambda x: x["age"])
map(str, [1, 2, 3])
filter(lambda x: x > 0, nums)

# 更 Pythonic 往往用列表推导（见进阶）
[x * 2 for x in nums if x > 0]
```

## 3.5 类与对象

```python
class User:
    species = "human"          # 类属性

    def __init__(self, name: str, age: int):
        self.name = name       # 实例属性
        self.age = age

    def intro(self) -> str:
        return f"{self.name}, {self.age}"

u = User("Tom", 25)
u.intro()
```

| 概念 | 说明 |
| --- | --- |
| `__init__` | 构造/初始化，不是「创建内存」本身 |
| `self` | 实例自身，必须显式写（第一个参数） |
| 实例方法 | 第一个参数是 `self` |
| 类方法 / 静态方法 | `@classmethod` / `@staticmethod`（按需学） |

## 3.6 继承

```python
class Animal:
    def speak(self):
        raise NotImplementedError

class Dog(Animal):
    def speak(self):
        return "wang"

super().__init__(...)   # 调父类初始化
```

- 多继承语法支持，实际项目里**慎用**；优先组合。

## 3.7 常用魔术方法（查表）

| 方法 | 何时触发 |
| --- | --- |
| `__str__` | `print(obj)`、 `str(obj)` |
| `__repr__` | 交互式显示、调试 |
| `__len__` | `len(obj)` |
| `__getitem__` | `obj[key]` |
| `__eq__` | `==` |

```python
def __repr__(self):
    return f"User(name={self.name!r})"
```

## 3.8 属性与封装习惯

```python
class Account:
    def __init__(self, balance: float):
        self._balance = balance   # 单下划线：约定「内部使用」

    @property
    def balance(self):
        return self._balance
```

- 无双下划线「真私有」，`__name` 会名称改写，一般了解即可。
